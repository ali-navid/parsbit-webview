# ParsBit App Builder - Generated Android WebView Project

این پروژه توسط ParsBit App Builder v0.1 ساخته شده است.

## مشخصات
- Android WebView
- JavaScript فعال
- DOM Storage فعال
- Upload فایل
- Download فایل
- دکمه Back
- Swipe Refresh
- لینک‌های داخلی داخل اپ
- لینک‌های خارجی با مرورگر سیستم
- minSdk 24
- targetSdk 36

## ساخت APK
1. یک Repository جدید در GitHub بسازید.
2. تمام فایل‌های این پروژه را در branch `main` قرار دهید.
3. به تب Actions بروید.
4. Workflow با نام `Android Build` را اجرا کنید.
5. بعد از سبز شدن Build، از بخش Artifacts فایل APK را دانلود کنید.

> این نسخه برای تست است و APK/AAB دیباگ تولید می‌کند. امضای Release و انتشار در کافه‌بازار در مراحل بعدی اضافه می‌شود.
